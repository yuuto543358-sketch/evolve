# EVOLVE（イボルブ）

**昨日の自分を、少しずつ超えていく。**

筋トレ・有酸素運動・食事（タンパク質）・身体の変化をまとめて記録して、
経験値・レベル・ステータスで成長をゲームのように実感できる、身体づくりアプリです。

- 目標は「細マッチョ」（あとから変更できます）
- 入力は少なく。前回の内容が自動で入るので、数秒で記録できます
- 記録しない日があっても、ペナルティはありません
- iPhoneのホーム画面に追加すると、アプリのように使えます（オフラインでも開けます）

---

## 📱 iPhoneで使えるようにする方法（はじめての人向け）

むずかしいプログラムの知識はいりません。順番にやれば大丈夫です。

### ステップ1：GitHub Pages（ギットハブ ページズ）をONにする

GitHub Pages は、このアプリを「インターネットで開けるページ」にしてくれる無料の機能です。

1. パソコンかスマホのブラウザで、GitHubのこのリポジトリ（`evolve`）のページを開きます
2. 上のほうにある **「Settings（設定）」** をおします
3. 左側のメニューから **「Pages」** をおします
4. 「Build and deployment」の **Source** が「Deploy from a branch」になっているのを確認します
5. **Branch** のところで、アプリが入っているブランチ（例：`main`）を選び、その横を **`/ (root)`** にします
6. **「Save（保存）」** をおします
7. 1〜3分ほど待って、ページを再読み込みすると、上のほうに
   `https://（あなたのユーザー名）.github.io/evolve/` というアドレスが出ます。これがアプリの住所です 🎉

> 💡 まだ `main` ブランチにアプリが入っていない場合は、先にプルリクエストを「Merge（マージ）」してください。

### ステップ2：iPhoneのホーム画面に追加する

1. iPhoneの **Safari（サファリ）** で、さっきのアドレスを開きます
2. 画面の下にある **共有ボタン**（四角から上向きの矢印が出ているマーク）をおします
3. メニューを下にスクロールして **「ホーム画面に追加」** をおします
4. 名前が「EVOLVE」になっているのを確認して、右上の **「追加」** をおします
5. ホーム画面に緑色の EVOLVE アイコンが出たら完成です！

これからは、**ホーム画面のアイコンから開いて** 使ってください。

## 👆 使い方のコツ

- 画面右下の **＋ボタン** を押すと、どの画面からでもすぐに記録できます（プロテインはワンタップ）
- 記録の一覧は、行を **左にスワイプ** すると「削除」ボタンが出ます（消しても「取り消す」で元に戻せます）
- 下から出てくる画面（シート）は、上の部分を **下に引っぱる** と閉じられます
- 数字の **＋／−ボタンは長押し** すると、どんどん数字が変わります
- 体重などのグラフは **指でなぞる** と、その日の値が見られます
- 下のタブで今いる画面をもう一度押すと、画面の一番上にもどります

### 📸 体の写真（上半身）の撮り方
- GROWTH →「写真」→ **ガイド付きで撮影** を押すと、カメラが開きます（はじめてのときは「カメラを許可」を押してください）
- 画面の **点線のシルエット** に、頭・肩・おへその位置を合わせて撮ります
- 上の **水平器** が緑色の「まっすぐ」になると、スマホがまっすぐです
- **「前回を重ねる」** で前回の写真がうっすら表示されるので、立つ位置をそろえられます
- 1人で撮るときは **タイマー（3秒・10秒）** が便利です
- 撮った写真は **「コマ送りで見る」** でパラパラ漫画のように変化を見返せます（左右スワイプで1枚ずつ）
- 体重のグラフをタップすると、**その日の写真** が下に出ます（金色の輪は「写真がある日」の印です）

## 💾 データについて（大切なこと）

- 記録は **あなたのiPhoneの中** に保存されます。インターネット上には送られません
- アプリを閉じても、iPhoneを再起動しても、記録は消えません
- ただし、iPhoneを買い替えるときや、もしものときのために、
  ときどき **PROFILE → 「バックアップ」** でデータを保存しておくと安心です
  - バックアップしたファイルは「ファイル」アプリやiCloud Driveに保存できます
  - 新しいiPhoneでは **PROFILE → 「復元する」** でそのファイルを選ぶと、記録が元にもどります
- Safariで直接開いた場合と、ホーム画面のアイコンから開いた場合では、保存場所が別々になることがあります。いつもホーム画面のアイコンから開くのがおすすめです

## 🎮 デモデータで試す

PROFILE →「デモデータで試してみる」で、約7週間分のサンプル記録が入った状態を見られます。
デモは別の場所に保存されるので、あなたの記録とは混ざりません。画面上の「デモを終了」でいつでも戻れます。

## 画面の構成

| タブ | できること |
| --- | --- |
| HOME | レベル・経験値・ステータス・今月の運動・カレンダー・最近の成長・今日のおすすめ |
| TRAINING | 筋トレ（複数種目をまとめて記録）・有酸素運動（消費カロリー自動計算）・履歴 |
| NUTRITION | プロテインのワンタップ記録・朝昼夕・間食・タンパク質の進み具合・カロリー参考値 |
| GROWTH | 体重・体脂肪率・筋肉量・ウエストのグラフ（日/週/月）・写真のビフォーアフター比較 |
| PROFILE | 称号・実績・プロフィール・設定・バックアップ/復元 |

## 経験値のしくみ（かんたんに）

| 行動 | 経験値 |
| --- | --- |
| 筋トレ | 1日20XP＋種目数×5XP＋回数に応じて最大30XP（1日最大80XP） |
| ランニング | 15XP＋1kmごとに6XP |
| ウォーキング | 5XP＋1分ごとに0.4XP |
| 食事の記録 | 朝・昼・夕・間食 各5XP |
| タンパク質の目標達成 | 20XP |
| 身体測定 / 写真 | 15XP / 10XP（1日1回） |
| 週3日運動 | 50XP（週5日でさらに30XP） |
| 実績の達成 | 20〜250XP |

経験値は記録から毎回自動計算されるので、同じ記録を何度も入れても1日の上限以上は増えません。
記録を修正・削除すると、経験値も自動で正しく直ります。
消費カロリー・ステータスはすべて目安（ゲーム内の指標）で、医学的な測定値ではありません。

## 開発者向けメモ

- 技術：HTML / CSS / JavaScript（ESモジュール）だけ。ビルド不要・外部ライブラリなし
- 保存：IndexedDB（`evolve` データベース。デモは `evolve-demo`）
  - 記録は `id`（UUID）・`createdAt`・`updatedAt` を持つので、将来のクラウド同期に対応しやすい設計
  - 写真は縮小（最大1280px JPEG）して保存。一覧用の小さなサムネイルは別に保持
- PWA：`manifest.webmanifest` と `sw.js`（Service Worker）
- パスはすべて相対パス（`./`）なので、`https://ユーザー名.github.io/evolve/` のようなサブフォルダでも動きます

### ファイル構成

```
index.html              画面の土台・iPhone用の設定
manifest.webmanifest    ホーム画面に追加したときの名前・アイコン・色
sw.js                   オフライン対応（Service Worker）
css/style.css           デザイン
icons/                  アプリアイコン・ロゴ（icon.svg が元データ）
js/app.js               起動・タブ切り替え・経験値の反映
js/game.js              経験値・レベル・ステータス・実績の計算
js/calc.js              消費カロリーの推定
js/store.js / db.js     データ保存
js/records.js           記録の表示・編集・削除
js/backup.js            バックアップと復元
js/views/*.js           各タブの画面
tools/generate-icons.js アイコンPNGの作り直し用
tools/generate-splash.js iPhoneの起動画面の作り直し用
js/quick.js             ＋ボタンのクイック記録
js/camera.js            ガイド付き撮影（シルエット・水平器・タイマー）
js/photos.js            写真の保存・コマ送りビューア
```

### アプリを更新したとき

`sw.js` の先頭にある `VERSION`（例：`evolve-v1.0.0`）の数字を上げてください。
利用者がアプリを開いたときに「新しいバージョンがあります」と表示され、「更新」で最新版になります。
ファイルを追加した場合は `sw.js` の `APP_SHELL` にも追加してください。

### アイコンを作り直すとき

`icons/icon.svg` を編集してから、`node tools/generate-icons.js` を実行すると、PNG画像がまとめて作り直されます（Node.js と Playwright が必要）。
